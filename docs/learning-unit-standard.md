# Learning unit standard

Every unit must be structured as an engineering exercise.

## Required sections

1. **Objective** — observable capability to acquire.
2. **Theory** — mental model, terminology, diagrams, and references.
3. **Guided implementation** — incremental code with explanations.
4. **Experiment** — hypothesis, variables, procedure, observations, conclusion.
5. **Tests** — unit and integration tests as appropriate.
6. **Challenge** — a task completed without copying the guided solution.
7. **Review** — correctness, maintainability, security, performance, cost.
8. **Evidence** — commit, test output, experiment report, and retrospective.

## Completion rubric

| Level | Evidence |
|---|---|
| Foundation | Correct explanation and reproducible implementation |
| Practitioner | Independent implementation and meaningful tests |
| Professional | Measured trade-offs, robust failure handling, security and operational considerations |
